# Qel

**Knowledge meets agency.**

Qel is a personal knowledge base that captures everything you think, read, and say — then makes it actionable through AI.

---

## What is Qel?

We don't trust our memory, so we write things down. But "writing things down" today means scattering thoughts across Notion, Google Keep, Google Docs, voice memos, and WhatsApp. The result is fragmented context — ideas lost across a dozen apps.

Qel solves this. One place for every thought, note, and reference. Intelligent auto-categorization. Natural language search. And an open knowledge layer that AI agents can use to act on your behalf.

## Architecture

```
  Layer 3 — Agent Layer          (AI agents that act on your knowledge)
  Layer 2 — Context Layer        (MCP / Mem0-style API for agent access)
  Layer 1 — Knowledge Ingestion  (Capture · Search · Categorize)  ← MVP
```

## MVP — Knowledge Ingestion Layer

The first release focuses on effortless capture and intelligent retrieval:

- **Quick capture** — text and voice from mobile, web, browser extension
- **Auto-categorization** — smart tagging without manual effort
- **Natural language search** — find things the way you remember them
- **Visual browse** — mymind-inspired grid layout
- **Save to Qel** — OS context menus, share sheets, browser extension
