# Feature Spec: Idea Backlog Triage & Prospective Co-Creation
*17+ Project Backlog Matching, Pinterest Aesthetic Pairing & Emergent Scaffolding*

---

## 1. Feature Overview

The Idea Backlog transforms a static list of 17+ raw project concepts (voice fragments, rough notes, sketch cards) into an **Active Creative Sounding Board**.

---

## 2. Dynamic Triage Dimensions

During conversational sparring, Qel surfaces backlog ideas matched to three live vectors:
1. **Aesthetic Resonance**: Pairing a software concept with your visual Pinterest boards to define its design language (e.g. brutalist typography, tactile cybernetics).
2. **Current Energy Vector**: High-focus deep builds vs. playful weekend micro-experiments.
3. **AI Capability Match**: Triggering suggestions when a new frontier model (e.g. Gemini 3.7 Flash high reasoning, free tiers) makes an old idea a rapid one-shot build.

---

## 3. Emergent Downstream Agency (Vibe-Coding Scaffolding)

When a conversational sparring session crystalizes an architecture:
* Qel formats the PRD, database schemas, and step-by-step implementation prompt packs for modern agentic IDEs (Cursor, Antigravity, Windsurf).
* Eliminates the "Planning Tax", taking you from raw thought to live running code in minutes.
