# Feature Spec: Cognitive Event Graph & Epistemic Precision Engine
*Hierarchical Memory Topology, Meta-Context Envelopes & Asynchronous Void Resolution*

---

## 1. Feature Architecture

The Cognitive Event Graph (CEG) is the associative brain of Qel. It models process, flow, causality, and belief precision across years of multi-modal checkpoints.

```
┌──────────────────────────────────────────────────────────────────────────┐
│                   THE COGNITIVE EVENT GRAPH TOPOLOGY                     │
├──────────────────────────────────────────────────────────────────────────┤
│ Level 4: Macro Life Arcs (Multi-Year Trajectories & Philosophy)          │
│ Level 3: Narrative Episodes (Seasons, Breakthroughs, Projects)           │
│ Level 2: Sub-Elements & Premises (Causal "Why", Emotional Tensions)      │
│ Level 1: Semantic Entities (Concepts, People, Tools, Places)             │
│ Level 0: Multi-Modal Atoms (Audio, Visual Pins, Web Clippings, Sketched) │
└──────────────────────────────────────────────────────────────────────────┘
```

---

## 2. The Meta-Context Envelope & Epistemic Precision

Every artifact ingested into Qel is wrapped in a 4-tier Meta-Context Envelope:
1. **Ground Truth Facts ($\Pi = 1.0$)**: Verbatim transcripts, recording timestamps, source domains, exact image dimensions.
2. **High-Confidence Signals ($\Pi \approx 0.85 - 0.95$)**: Speech rate (WPM), vocal fatigue index, circadian nadir markers, OCR text.
3. **Probabilistic Hypotheses ($\Pi \approx 0.30 - 0.60$)**: Inferred sleep deficit, latent emotional loops.
4. **Open Epistemic Voids**: Missing data sockets logged to `epistemic_void_index`.

---

## 3. Asynchronous Temporal Void Resolution (Dangling Sockets)

To avoid cognitive fatigue, Qel does not interrogate the user for every missing variable.
* **The Dangling Socket**: Open voids are stored quietly in the database.
* **Asynchronous Matcher**: When future artifacts arrive (e.g. a morning voice note 2 days later stating that sleep resolved the frustration), the `EpistemicVoidMatcherDO` retroactively binds the future checkpoint to the past void, confirming the causal edge in the graph automatically.
